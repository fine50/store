العودة للوحة الإدارة عرض المتجر

⚙️ معالج إعداد المتجر

الصق كود Firebase أدناه، وسيتم توليد ملف config.js

1) إعداد Firebase

اذهب إلى Firebase Console وأنشئ مشروعاً، ثم:
• Build → Realtime Database → Create Database → Test Mode
• Build → Authentication → Get Started → Anonymous → Enable
• ⚙️ Project Settings → Your apps → أيقونة الويب </> → انسخ كود Firebase بالكامل.

💡 الصق الكود كما هو من Firebase Console بدون تعديل.

2) مفتاح ImgBB

اذهب إلى api.imgbb.com → اضغط Get API Key → سجّل بحساب Google → انسخ المفتاح.

3) حساب المالك (للدخول)

هذا الحساب سيُستخدم للدخول إلى لوحة الإدارة. استخدم أحرفاً إنجليزية وأرقاماً فقط.

📋 خطوة أخيرة: انسخ هذا المحتوى

اضغط "نسخ المحتوى"، ثم افتح ملف config.js على جهازك والصق فيه المحتوى الجديد (احذف كل القديم أولاً)، ثم احفظ.

🎉 تم بنجاح!

تم توليد config.js. اذهب الآن إلى لوحة الإدارة.

🛠️ فتح لوحة الإدارة 🏪 فتح المتجر

📌 بعد توليد الملف:

  1. انسخ محتوى config.js من الصندوق الأزرق أعلاه.
  2. افتح ملف config.js على جهازك (بالمفكرة أو أي محرر نصوص).
  3. احذف كل محتواه القديم، والصق المحتوى الجديد، ثم احفظ.
  4. ارفع الملف إلى استضافتك (استبدل القديم).
  5. افتح admin.html وسجّل الدخول.
